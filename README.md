# Python Calculator

A simple command-line calculator built with Python. This project allows users to perform basic arithmetic operations such as addition, subtraction, multiplication, and division using keyboard input.

## Project Overview

This project is a beginner-friendly Python application designed to practice core programming concepts such as:

- Variables and user input
- Functions
- Conditional statements
- Error handling
- Loops
- Basic calculator logic

The program asks the user for two numbers and an operation, then prints the result. It also gives the user the option to continue calculating using the previous result.

## Technologies Used

This project uses the following technologies and Python features:

- Python 3
- Built-in `input()` function for user interaction
- Built-in `print()` function for output
- Python functions for arithmetic operations
- Dictionary-based operation mapping
- `try` and `except` for handling invalid input values
- `while` loop for repeated calculations

## Features

- Addition (`+`)
- Subtraction (`-`)
- Multiplication (`*`)
- Division (`/`)
- Input validation for numeric values
- Invalid operation handling
- Continue calculating with the previous result

## How to Run

1. Open a terminal in the project folder.
2. Run the program:

```bash
python main.py
```

3. Enter the first number, choose an operation, and enter the second number.

## Example

```bash
Enter first number: 10
+
-
*
/
Enter operation: +
Enter second number: 5
10.0 + 5.0 = 15.0
```
